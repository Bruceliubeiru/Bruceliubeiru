# GEO Multi-Agent Architecture

## Vision

Build an AI-native GEO operating system powered by multiple specialized agents.

## Core Agents

### 1. Research Agent

Responsibilities:

- collect GEO trends
- analyze AI answers
- identify competitor visibility
- monitor citation patterns

### 2. Rewrite Agent

Responsibilities:

- rewrite content for GEO
- improve AI readability
- optimize FAQ structure
- improve citation readiness

### 3. Experiment Agent

Responsibilities:

- run GEO tests
- compare before/after results
- score visibility changes
- recommend next experiments

### 4. Competitor Agent

Responsibilities:

- monitor competitor visibility
- analyze why competitors rank higher
- compare content structure
- identify GEO gaps

### 5. Report Agent

Responsibilities:

- generate weekly GEO reports
- summarize experiment results
- produce executive insights

## Long-Term Direction

Create a collaborative GEO intelligence system.
