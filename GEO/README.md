# GEO Growth OS

**GEO Growth OS** is an AI Native Growth Operating System for the AI search era.

It is not a normal content repository. It is designed to turn GEO strategy, prompt engineering, skill systems, workflow automation, and experiment data into long-term growth assets.

## 1. Positioning

GEO Growth OS helps a brand, product, or business become easier to be discovered, understood, quoted, compared, and recommended by AI search engines and generative assistants.

The strategic shift:

- Past: optimize collaboration between people.
- Now: optimize collaboration between AI and business growth.

## 2. Mission

Systemize GEO capability, assetize prompt and skill knowledge, and build a repeatable AI visibility growth loop.

## 3. Core Principles

1. **AI-readable first**: every asset should be structured, specific, and easy to quote.
2. **Evidence-based growth**: no opinion-only content; every claim needs proof, comparison, or example.
3. **System over heroics**: growth should move from people-driven to system-driven.
4. **Experiment loop**: observe AI answers, improve content, and republish.
5. **Business-first AI**: AI tools are not the goal; measurable growth is the goal.

## 5. Core Modules

### Prompt System

Stores GEO prompts, AI-search prompts, content-optimization prompts, and prompt testing patterns.

### Skill System

Turns repeated business capabilities into reusable skills, such as:

- GEO Audit Skill
- AI Visibility Skill
- Competitor Answer Skill
- Content Rewrite Skill
- ROI Skill

### Workflow Engine

Connects repeatable workflows such as:

- Feishu table input
- AI content scoring
- weekly GEO report
- content republishing
- experiment review

### GEO Experiments

Records what actually improves AI answer visibility:

- citation pattern
- answer position
- content structure
- source trust
- comparison wording
- FAQ coverage

## 6. Recommended Stack

- IDE: Cursor
- Workflow: Dify / Feishu automation
- Agent: OpenHands / Codex-style coding agent
- Backend: FastAPI
- Frontend: Next.js
- Data: Python + Pandas
- Vector DB: Chroma / PGVector
- Knowledge Base: Feishu + Git
- AI SDK: OpenAI SDK

## 7. Operating Loop

```text
Research → Positioning → Prompt → Skill → Content Asset → Distribution → AI Answer Testing → Optimization → Republish
```

## 8. 30-Day MVP Goal

1. Build the first GEO positioning map.
2. Create 10 AI-friendly content assets.
3. Create 30 FAQ-style answer assets.
4. Create 3 comparison pages.
5. Create 3 case-study pages.
6. Run weekly AI answer tests.
7. Produce one GEO improvement report per week.

## 9. Success Metrics

- AI mentions increase.
- AI answer quality improves.
- More answers cite or summarize owned content.
- FAQ coverage increases.
- Content can be reused by sales, marketing, and strategy teams.
- Prompt and skill assets become reusable across projects.

## 10. Strategic Essence

GEO Growth OS turns GEO, AI, and growth capabilities into organizational assets.

The goal is simple:

> Make the business easy for AI to understand, trust, cite, and recommend.
