# GEO Scoring Guide

## Purpose

The GEO Scoring Engine measures how AI-friendly and GEO-ready content is.

## Current Dimensions

| Dimension | Max Score |
|---|---|
| Semantic Clarity | 20 |
| Citation Readiness | 20 |
| FAQ Coverage | 15 |
| Comparison Readiness | 15 |
| Authority Signal | 15 |
| AI Readability | 15 |

## Scoring Logic

### Semantic Clarity

Measures:

- definition quality
- explanation clarity
- business understanding

### Citation Readiness

Measures:

- quote-ready wording
- concise explanation
- reusable phrasing

### FAQ Coverage

Measures:

- user intent coverage
- direct question answering

### Comparison Readiness

Measures:

- competitor comparison
- alternative explanation
- differentiation clarity

### Authority Signal

Measures:

- proof points
- metrics
- cases
- benchmarks

### AI Readability

Measures:

- formatting structure
- headings
- bullets
- markdown clarity

## Long-Term Goal

Create measurable GEO ranking signals.
