# GEO Dashboard Architecture

## Purpose

Create a GEO visibility operating dashboard.

## Core Modules

### 1. AI Visibility Overview

Track:

- AI mention frequency
- citation frequency
- GEO score trend
- competitor visibility delta

### 2. Query Monitor

Track:

- target query
- AI engine
- ranking position
- answer quality
- citation source

### 3. Experiment Timeline

Visualize:

- experiment history
- before/after results
- visibility improvement
- GEO optimization cycle

### 4. Competitor Intelligence

Analyze:

- why competitors rank better
- comparison patterns
- FAQ coverage gaps
- authority gaps

### 5. Skill System Panel

Manage:

- GEO skills
- prompts
- reusable workflows
- AI rewrite templates

## Recommended Frontend Stack

- Next.js
- TypeScript
- TailwindCSS
- shadcn/ui
- Vercel
