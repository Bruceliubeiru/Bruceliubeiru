# GEO Backend

## Purpose

Backend services for GEO Growth OS.

## Planned Services

### 1. GEO Audit API

Analyze AI readability and GEO visibility.

### 2. AI Visibility Tracker

Track whether a brand appears in AI answers.

### 3. FAQ Generator

Generate AI-friendly FAQ assets.

### 4. Competitor Comparison Engine

Compare AI visibility between brands.

## Recommended Stack

- FastAPI
- Python
- Pandas
- OpenAI SDK
- Chroma / PGVector

## Planned Endpoints

```text
POST /geo/audit
POST /geo/faq
POST /geo/rewrite
POST /geo/visibility
POST /geo/competitor
```
