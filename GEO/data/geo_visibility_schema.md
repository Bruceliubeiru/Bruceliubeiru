# GEO Visibility Schema

## Purpose

Track AI visibility and GEO experiment results.

## Core Dimensions

| Field | Description |
|---|---|
| query | target AI query |
| engine | ChatGPT / Gemini / Perplexity |
| brand_mentioned | whether our brand appears |
| competitor_mentioned | whether competitor appears |
| citation_used | whether source citation appears |
| answer_position | ranking/order in answer |
| faq_coverage | FAQ completeness |
| comparison_quality | comparison quality |
| geo_score | GEO score |
| timestamp | experiment timestamp |

## Long-Term Goal

Build GEO ranking factor datasets.
